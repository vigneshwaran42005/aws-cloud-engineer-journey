# Day 01 – Cloud Computing Basics ☁️

## 📅 Topic

**Cloud Computing Basics**

## 📌 What I Learned

Cloud computing is the delivery of computing resources over the internet on a pay-as-you-go basis.

Instead of purchasing and maintaining physical servers, organizations can use cloud services such as compute, storage, databases, networking and security from cloud providers.

## 🏠 Real-World Example – Renting a House

A simple way to understand cloud computing is by comparing it with **renting a house**.

If we want to own a house, we need to:

* Buy land
* Construct the house
* Invest a large amount of money
* Maintain the property
* Take care of repairs and infrastructure

Instead, if we **rent a house**:

* We don't need to buy the property
* We pay rent based on the agreement
* We can use the house when needed
* We don't have to own the entire infrastructure
* We can move to another house when our requirements change

### ☁️ How This Relates to Cloud Computing

The same concept applies to cloud computing.

Instead of purchasing and maintaining physical servers, a company can **rent computing resources from a cloud provider** such as AWS and pay for the resources it uses.

| 🏠 House Rental                    | ☁️ Cloud Computing                               |
| ---------------------------------- | ------------------------------------------------ |
| Rent a house                       | Rent cloud resources                             |
| Monthly rent                       | Pay-as-you-go                                    |
| No need to buy the property        | No need to buy physical servers                  |
| Owner manages the property         | Cloud provider manages underlying infrastructure |
| Move to a bigger house when needed | Scale resources when needed                      |

### 💡 Simple Example

**Traditional IT:**

`Buy Server → Install → Maintain → Upgrade Hardware`

**Cloud Computing:**

`AWS → Provision EC2 → Run Application → Pay for Usage`

> **Cloud computing is similar to renting a house: instead of owning and maintaining the entire infrastructure, we use the resources we need and pay for what we use.**

## ☁️ Major Cloud Providers

* Amazon Web Services (AWS)
* Microsoft Azure
* Google Cloud Platform (GCP)

## 🏗️ Cloud Service Models

### 1. IaaS – Infrastructure as a Service

Provides virtualized infrastructure such as:

* Virtual Machines
* Networking
* Storage

**Example:** Amazon EC2

### 2. PaaS – Platform as a Service

Provides a platform for developing and deploying applications without managing the underlying infrastructure.

**Example:** AWS Elastic Beanstalk

### 3. SaaS – Software as a Service

Provides ready-to-use software through the internet.

**Examples:** Gmail, Microsoft 365

## ⭐ Benefits of Cloud Computing

* Scalability
* High availability
* Flexibility
* Cost optimization
* Global accessibility
* Faster deployment
* Disaster recovery
* Reduced hardware maintenance
